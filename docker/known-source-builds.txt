# Requirements that have no installable wheel and are allowed anyway.
#
# scripts/audit_node_requirements.py fails the build on anything here that is not
# listed. A name on this list is a promise that the source build has been dealt with -
# so the reason has to say how, not just that it was noticed.
#
# Format: name  # reason

sam2   # VCS requirement of ComfyUI-Impact-Pack. The image bake installs commit
       # 2b90b9f5ceec907a1c18123530e92e794ad901a4 with SAM2_BUILD_CUDA=0 and
       # --no-build-isolation, under the cu130 constraints. The catalog list omits the
       # git line, and requirements_baked skips the pack requirements.txt at pod boot.
       # A GitHub fallback does not reinstall sam2; the image copy is what imports.

dlib   # sdist only; PyPI has no wheel for any Python. Built into the image by its own
       # pinned Dockerfile layer so no pod ever compiles it.

nvidia-vfx  # NVIDIA wheel-stub used by Nvidia_RTX_Nodes_ComfyUI. The catalog supplies
            # https://pypi.nvidia.com/ and the launcher uses --no-build-isolation, so the
            # stub selects NVIDIA's prebuilt CPython 3.12 manylinux x86_64 wheel.
